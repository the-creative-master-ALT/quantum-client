Toggle mods here. Every enabled mod is injected into supported builds automatically — whenever you launch or embed a game — so nothing extra needs downloading.

How mods load: enabled mods are injected into launcher-hosted sessions (embedded player, This tab, popup, and new-tab wrapper). A badge in the game window reports exactly how many loaded. ModAPI mods need a build that exposes Eaglercraft's ModAPI hook — the builds bundled in this archive do not ship it, so those will report “needs ModAPI”. Any build mods (Music Player, Screenshot) work everywhere, so use those to confirm injection is live.
