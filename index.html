Before you play

  • Every build is one self-contained .html file — the first launch downloads the whole game (some are 80 MB), then your browser caches it.
  • Click inside the game to capture your mouse. Press Esc inside the game to release it.
  • WASM-GC builds are smaller and start faster, but need a browser from 2023 or newer.
  • Touch controls: the mobile-oriented builds (tagged mobile) work best on phones.
  • Saves and settings live in that browser's local storage — clearing site data wipes your worlds.

Built with vanilla HTML, CSS and JS. No trackers, no telemetry, no build step.
